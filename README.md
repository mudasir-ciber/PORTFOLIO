# Portfolio — Freelance Video Editor

Premium personal portfolio for a freelance video editor.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Motion (`motion`)

## Development

```bash
npm install
npm run dev
```

- Phase 1 — Design system & visual foundation (current)
